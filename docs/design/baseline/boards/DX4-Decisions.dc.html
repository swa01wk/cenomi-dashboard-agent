DXD-37Versioned recoveryA successful retry of a failed node is a new run that creates answer v2 (“revises v1”). v1 is preserved exactly as generated, labelled “superseded · kept unchanged”, and both appear in the inspector’s Versions list. DXD-38Context isolation rulesSwitching threads, changing roles, removing scope chips and resuming investigations can never widen authorization or import context implicitly. Imports and resumes are re-checked against the current access scope; mismatches are refused or dropped with a banner. Another role’s investigations are not listed, opened or importable. Removing a scope chip widens only to the access scope; boundaries cannot be removed.J7 · J10 · server AccessScopeApproved
DXD-39Accessibility of evidence, activity and selectionEvidence labels, coverage, version and connection states are text. Selectable rows, bars and cells expose aria-pressed and a text state. The inspector is a dialog that takes focus, supports Escape and restores focus; tabs use arrow keys. One polite live region announces run status. Text contrast ≥ 4.5:1 on all labels and controls (automated).DX4 · DX5 · GD (axe-core on real build)Approved
