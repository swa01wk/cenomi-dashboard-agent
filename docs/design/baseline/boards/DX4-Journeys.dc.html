Workspace · new investigation

Reconnect and replay by seqDuplicates ignoredStop → CANCELLEDRun again = new run
  1. Ask which Central malls have the most vacant unitsThree parallel tool calls start.
  2. The connection dropsA strip says “Connection lost after event #N. Reconnecting”. The client resumes from the run ledger (GET /runs/{id}/events?after=N); replayed duplicates are dropped by (runId, seq).
